# Okavo mobile product presentation

This approval deck tells the Android and iOS product story from the perspective
of a public visitor, buyer, developer and administrator. It covers the
marketplace journey, role-specific features, trust boundaries, architecture,
quality evidence and remaining store-owner actions.

## Presentation files

- `generated/okavo-mobile-product-story.pptx` — presentation copy
- `generated/okavo-mobile-product-story.pdf` — share/review copy
- `generated/okavo-contact-sheet.jpg` — whole-deck visual overview
- `generated/slides/` — individual PNG and SVG slides
- `presentation.json` — editable narrative, palette and slide content
- `assets` — verified Android release screenshot used on the cover

## Claim boundary

The deck describes the product that exists in this repository. It does not
claim App Store or Play Store approval, a signed iOS binary, completed
marketplace payments, or a guarantee that no future defect can exist. Payments
remain deliberately disabled until a verified money flow is available.
